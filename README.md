# Circle ⭕ - Friends Photo Moments

A private group social web app designed for close friend circles.

## ✨ Features
- **Friend Connections ("Also on Circle")**: Find and connect with your friends on the app.
- **Private Rooms**: Create custom countdown circles (1h, 2h, 4h, or custom durations) with your friends.
- **Live Camera Only**: No camera roll uploads allowed. Real-time, authentic moments captured directly via your device camera.
- **Zero Competition**: No likes count or vanity metrics.
- **End-of-Round Compilation Dump**: When the countdown completes or the room ends, all friends' captured moments are compiled into a shared memory dump.
- **Initial Avatars & Custom Profile Photos**: Clean name initials avatar by default, with custom profile photo upload support.
- **Dark Mode**: Seamless toggle between Dark and Light mode.
- **Native Mobile Experience**: Full-screen responsive viewport for iOS Safari and Android Chrome with camera access.

## 🚀 How to Host on GitHub Pages
1. Create a new repository on GitHub (e.g. `circle-app`).
2. Upload `index.html`, `README.md`, `.nojekyll`, and the `assets/` folder.
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your live app will be published at:
   `https://<your-username>.github.io/<repository-name>/`
6. Open the link on your mobile phone and tap **Add to Home Screen** for a full native app feel!
